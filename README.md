# 📥 Installation Instructions

### Install the Application

1. Download the latest APK from the provided download link.
2. Open the downloaded APK file on your Android device.
3. If Android displays a security warning, tap **Settings**.
4. Enable **Allow from this source** for the application you used to download the APK (such as Chrome or Files).
5. Return to the APK installation screen.
6. Tap **Install**.
7. Wait for the installation to complete.
8. Open the application and enjoy!

### 🔐 How to Enable Unknown App Installation

If you cannot install the APK, follow these steps:

1. Open your phone's **Settings**.
2. Go to **Security & Privacy** or **Privacy**.
3. Open **More security settings** or **Special app access**.
4. Select **Install unknown apps**.
5. Choose your browser or file manager (Chrome, Files, etc.).
6. Enable **Allow from this source**.
7. Return to the downloaded APK and install it.

**Note:** Settings may vary depending on your Android device and version. Only install APK files from trusted sources.

### 🔄 Update the Application

1. Open the installed application.
2. If a new version is available, an **Update Available** notification will appear.
3. Tap **Download & Install Update**.
4. Wait for the latest APK to download.
5. Tap **Install** when Android prompts you.
6. Once installation finishes, open the updated application.

**Important:** You do not need to uninstall the existing application before updating it. The new version must use the same package name and a compatible signing key.
