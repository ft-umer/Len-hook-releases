## 📥 Installation Instructions

1. Click the download link above.
2. Open the latest GitHub Release.
3. Download the `.apk` file.
4. Open the downloaded APK on your Android device.
5. If Android displays a security warning, tap **Settings**.
6. Enable **Allow from this source** for Chrome or your file manager.
7. Return to the APK installation screen.
8. Tap **Install**.
9. Wait for installation to complete.
10. Open the application.

## 🔐 Enable Installation from Unknown Apps

If Android does not allow APK installation:

1. Open your phone's **Settings**.
2. Go to **Security & Privacy**.
3. Select **Install unknown apps** or **Special app access**.
4. Choose your browser (Chrome) or file manager.
5. Enable **Allow from this source**.
6. Return to the downloaded APK and install it.

*Note: Settings may differ depending on your Android device and version.*

## 🔄 Update the Application

1. Open the installed application.
2. If a new version is available, an **Update Available** notification will appear.
3. Tap **Download & Install Update**.
4. Wait for the APK to download.
5. Tap **Install** when Android prompts you.
6. Your application will be updated.

**Important:** You do not need to uninstall the existing application. Updates require the same package name and a compatible signing key.
